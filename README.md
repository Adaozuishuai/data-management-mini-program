# Data Management Mini Program

HERO 研究电子病例报告微信小程序。当前版本用于演示病例建档、访视填写、用药记录与草稿保存。

## 目录

- `miniprogram/` 小程序应用入口、表单定义及本地记录存储。
- `miniprogram/pages/index/` 病例列表、访视和表单界面。
- `project.config.json` 微信开发者工具项目配置。

## 运行

在微信开发者工具中导入仓库根目录，选择有开发权限的小程序 AppID 后编译。演示记录保存在设备本地，请使用虚构病例。

在模拟器中可打开 `D001` 或 `D002`，选择访视，在表单中完成点选和录入。保存草稿后可以继续编辑，标记已填后可从病例详情回看。

## 真机体验

1. 在微信开发者工具点击「预览」，用有权限的微信扫码。
2. 需要共享体验时，点击「上传」，再到对应 AppID 的微信公众平台将开发版本设为体验版并添加体验成员。

更换 AppID 或测试设备后，请用虚构病例重新验证录入流程。正式共享数据需要接入受控的后端存储。
